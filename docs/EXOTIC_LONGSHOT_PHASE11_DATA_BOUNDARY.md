# Phase 11 data boundary

Phase 11 tests the race-centered longshot residual hypothesis without modifying
Forward Paper. This is research only, not evidence of positive expected value.

The approved free history documented in CURRENT_DATA_GAP.md ends in July 2021.
An independently approved free source covering the 2023 and 2024 development
periods has not been established. Therefore real-data Phase 11 evaluation
must remain blocked.

The CLI accepts only a dedicated development CSV under
data/research/development and requires a separately verified free-source
approval manifest before opening it. Never construct this CSV by filtering
the combined historical file. A provenance manifest is a human assertion,
not cryptographic proof of file contents.

Only synthetic-data unit tests and self-hosted smoke are approved for now.
No final-holdout data, paid data, or live bets may be used.
