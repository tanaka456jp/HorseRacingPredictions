# オッズ非依存 Top3＋独立穴馬の経済的評価ゲート

更新: 2026-10-27 / HorseRacingPredictions Draft PR #142

## 分離する3つの情報

1. **予測凍結（レース前）**: `FrozenOddsFreeForecast` に対象競走・出走馬全頭・モデルID・モデル学習終了日・予測作成日時・発走予定日時・勝利スコア・独立穴馬スコアを格納する。オッズ・払戻金・着順はこのオブジェクトに持たせない。指定日が2025年以降なら、最終評価対象を誤って研究用に使わないよう拒否する。
2. **買い目選択（レース前）**: `select_top3_and_outsider` が勝利モデルのスコア順に上位3頭を確定し、それ以外の出走馬から独立モデルのスコア最大の1頭を選ぶ。払戻データの変更で選択は変わらない。
3. **払戻照合（レース後）**: `FinalRaceSettlement` に公式な結果・100円あたりの単勝および複勝払戻金を別に受け取る。保存済み予測の4頭を変更せず、1競走あたり仮想投資額100円×2口（本命単勝1口＋穴馬複勝1口）の実現収支を集計する。

## 払戻ルール・データ品質

JRA公式 [勝馬投票券の発売について](https://www.jra.go.jp/kouza/baken/) に従い、複勝券の対象は5～7頭立てなら2着まで、8頭以上なら3着まで。4頭以下では複勝券が発売されないため、2口セットの比較対象から除外する。勝馬の100円単勝払戻金・複勝的中馬の100円払戻金は原資100円を含む。的中しない馬の払戻金は0。

当面の研究では、同着・返還・除外・発売後の頭数変更のような例外に十分な一次証拠がない競走は、**誤った確定収支を生成せず検証対象から除外**する。これらの競走を一般化して扱うまで、自動的な外挿を禁止する。

対象期間は現行研究の2024年12月31日以前に限定。出走馬の差異、複数優勝馬、不正な着順、重複レースID、事後予測、予測モデルの学習終了日が当該競走以降、オッズ使用、モデルID不一致等があれば拒否する。

## 統計的な評価と誤解の防止

**実現ROI**＝（確定払戻金合計÷仮想購入額合計）－1。これは実際に的中した過去の試験成績であり、未来の期待値とは異なる。

- **同日相関**: 同じ開催日の多数のレースを独立サンプルとして扱わない。開催日全体を1ブロックとする再標本化（ブロック・ブートストラップ）を実施する。
- **最小検証日数**: 相異なる開催日が10日未満の場合、信頼区間を表示しない。十分な期間・独立な未見データがなければ利益を実証したとは扱わない。
- **収益性の証明**: 実データの学習・時系列Out-of-Sample・十分な件数の事前凍結予想・価格の出所・取引コスト・市場変化を検証する必要がある。本研究モジュールは値がプラスでも`positive_expected_value_demonstrated=false`を維持する。
- **複数試行の補正**: 多数のモデル・条件を試し、最も良いROIだけを報告しない。統計上の独立検証と、同じ研究に使用していない最終ホールドアウト評価が別途必要。
- **利用権**: JRA-VAN等の利用契約および公開権限は別途確認する。GitHubやnoteへ元データをアップロードしない。実馬データを使った学習・払戻実測は今回未実施。

## 実行した検証と未達課題

`src/horse_racing_predictions/oddsfree_ev_research.py`および`tests/test_oddsfree_ev_research.py`の架空データでは、収支計算、払戻の整合性、払戻を変えても予想不変、モデル日付の前後関係、同日相関、複勝ルール、保護済みデータ遮断を検証。

ただし、PC②の約5.71GBの歴史データの権利／収録期間／払戻HR等の完全性は未確認。2026年に隔離保存した1,007件のRA/SEは研究用の2024年以前の学習原資ではない。**noteマガジンへの自動投稿も引き続き停止。**

## 2026-10-27：金曜日に存在しないレース当日の特徴量の遮断

noteの金曜事前予想では、レース終了後の実績に限らず**土日の開催直前にならないと分からない変数**も、未来情報の混入とみなす。

既存の `friday_predraw_features.py` と新規 `friday_feature_projection.py` を単一の厳格なポリシーへ統一した。実際の金曜予測経路で使用する `select_friday_predraw_research_features()` と `assert_friday_predraw_feature_list()` の双方が同じ許可リストを参照する。

- **使用しない当該レースの変数**：馬番号、相対馬番号、馬体重・増減、天気、馬場状態、最終出走頭数、確定出走頭数を分母として計算した値、当日最終負担重量とその平均差。これらをすでに分かっているものとして金曜モデルに学習させない。
- **条件付きで研究利用できる変数**：レース距離、年齢、競馬場、芝・ダート、性別、レースクラス、格付け、および各馬・騎手・調教師の**その日の前までの**履歴に基づく特徴量。金曜実運用時点で出走予定馬の同定・過去の成績・使用権限が確実に確認できることは、別途立証する必要がある。
- **厳禁**：当該レースの着順、上がり、コーナー通過順位、同日結果、オッズ、配当等を現在予測の特徴量に流用すること。
- 研究用の投影関数が成功しても `friday_roster_independently_verified=false`、`publication_authorized=false`。公式出走表・予想時刻・提供元の公開権限が不明な限り金曜投稿を開始しない。
- 既に保存された過去の2モデルが、上記制約を満たしているとは仮定しない。金曜適合モデルとして使用する場合は、対象の特徴量リストと学習終了期間を事前確認すること。

**実機予想成功を意味するものではない。** 架空の履歴データで特徴量制限および独立したCatBoost2モデルの学習が成立するかテストする。
