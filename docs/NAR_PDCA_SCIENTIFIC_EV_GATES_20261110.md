# NAR / JRA scientific PDCA: explicit evidence gate (2026-11-10)

## Objective, without outcome-based optimism
Demonstrate *positive after-all-cost expected net ROI* with **actual,
lawfully sourced independent data**, not synthetic tests or ranking
accuracy. Scientific failure/abandonment is allowed. No guarantee that
a profitable policy exists.

  all-race policy ROI **-24.4076%** over 13,402 retrospectively
  evaluable races. Treat this unconditional policy as **NO-GO**;
  retraining it until the same 2022 period turns positive is invalid.
  [Evidence run #42630314405](https://github.com/tanaka456jp/HorseRacingPredictions/actions/runs/42630314405).

  Attempted two 100-yen tickets per race: **11,800 yen** paper stake,

  **-38.8136%** paper ROI. See
  [#42821912761](https://github.com/tanaka456jp/HorseRacingPredictions/actions/runs/42821912761).
  No real tickets; no preoff odds at 07:56 or 08:00; hence not a

- 2023–2024 sealed independent OOS and 2025–2026 protected
  historical holdout must NEVER be unsealed for model exploration.
  Naturally newly gathered forward 2026-11-10-plus outcomes follow

  peeking into protected historical target datasets.

## Repeatable Plan–Do–Check–Act contract

1. **Plan / preregister.** Before the earliest event, commit a
   timestamped full schedule, chosen ticket types, selection model
   code hash, offered/unoffered stake policy, exception/refund handling,
   cost model, independent comparison, prespecified forecast/price
   capture window and stopping rule. Do not add a winning filter
   after inspecting the same outcomes or results.
2. **Do / prospectively capture.** Use official lawful public NAR data
   on PC② private D-drive only. Verify complete race/runner manifest
   before results, write immutable private original ZIP and selected
   candidate score snapshot, and send ONLY a blinded random-salt hash
   to an independent hosted GitHub receipt before first off.
   Capture *actually observed*, timestamped interim WIN/PLACE prices
   later while events remain truly ahead, leaving missing quotes
   missing. Respect official NAR 2-minute file refresh recommendation;
   never download or redisclose expired JRA-VAN content. No actual
   wagering or costs without approval.
3. **Check / independent settlement.** After events, reconcile every
   initially registered race, every sold/unoffered/refunded ticket,
   official 100-yen win/place dividends, declared extra fees, price
   timestamp and source age. No omission by realized outcome.
   Treat scratches as not offered, exclusions as refunded, DNFs as
   no-refund losses, and unknown statuses as HOLD. Calculate
   whole-day paper P&L **only if complete**. Never represent
   final pari-mutuel payouts as price guaranteed at bet placement.
4. **Act / evidence decision.** The research gate remains **HOLD**
   until enough independently timestamped forward races and prices
   support a preregistered, non-cherry-picked positive net ROI with
   a whole-race-day clustered uncertainty lower bound >0, after a
   justified multiple-testing correction and sensitivity for missing
   markets/cancellations/costs. Also require robustness over multiple
   independent race days and venues; a single profitable day is
   never 'proof'. Genuine realized profit additionally requires
   authorized actual purchase and execution receipts.
   If the lower bound is not clearly positive or legal/price data
   remain unavailable, record NO-GO, do not buy, and consider
   cancelling the project rather than endlessly retune.

## Strict limitations, CI and privacy
- CI using fictional records proves software behavior, not ROI.
- No model changes may use frozen future outcomes to select
  profitable-looking variants in the *same* evaluation period.
- No original ZIP, names, race IDs, source-specific payouts, scores,
  private salt or model binary may enter public GitHub logs or artifacts.
- Use Draft PR #142 for code and aggregate research evidence only;
  do not merge to main, run paid Codex, use paid data services, purchase
  tickets or claim live +EV.
- Fix identified data/path errors before model changes. Record per
  cycle the previous/new HEAD, concrete code/test/run change,
  independent result, explicit missingness and NEXT falsifiable test.
  No commits or CI loops without material hypotheses.
- If monitoring/scheduled work is blocked by the user's five-task
  limit, do not promise background progress that cannot run.
  Arrange for a free slot with user approval; do not interrupt
  unrelated active tasks without consent.
